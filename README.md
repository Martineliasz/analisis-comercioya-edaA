# Análisis Exploratorio de Datos y Modelo de Regresión Lineal del Comportamiento de Compra de Clientes en ComercioYA
## Descripción
Este proyecto aplica técnicas de Análisis Exploratorio de Datos (EDA) y regresión lineal para analizar el comportamiento de compra de clientes de la empresa ComercioYA.
El objetivo principal es identificar las variables que influyen en el monto total de compras y evaluar la relación entre la frecuencia de compra y el gasto total.
## Resultados principales
- Se identificó una correlación fuerte (r = 0.94) entre la frecuencia de compra y el monto total.
- El modelo de regresión lineal explicó el 88% de la variabilidad del gasto total (R² = 0.88).
- La frecuencia de compra es el principal predictor del monto total.
- El género no mostró influencia significativa en el comportamiento de gasto.
